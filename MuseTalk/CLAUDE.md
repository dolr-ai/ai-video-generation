Goal:
1. You are tasked with setting up .venv which is present in the root directory of the project.
2. You need to refer to README.md of MuseTalk project to understand the dependencies and the steps to set up the .venv.
3. You need to strictly use `uv` to install dependencies.
4. You should use docs folder to write 2 files:
    1. venv_setup.md: this should contain the steps which were tried and worked fine in the first attempt.
    2. venv_setup_errors.md: this should contain the steps which were tried and did not work, in case some error occured, what steps were taken to fix it.
5. once .venv is done try doing inference mentioned in the README.md of MuseTalk project.
